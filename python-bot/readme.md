# PYTHON BOT
## Getting Started
On a file with end .env you can write your token access API to start programming the BOT, the with the command:

```
python3 -m venv environment 
```

create a virtual environment for work with the dependencies to install. Once the virtual environment was created, activate with:

```
source environment/bin/activate
```

then you type and execute:

```
pip install -r requirements.txt
```

When you finish all this steps, you can program and run your own bot
